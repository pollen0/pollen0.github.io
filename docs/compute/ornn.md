# Ornn

Ornn has two branches: **Ornn Compute** and **Ornn Data**.

Through Ornn Compute, you can access the compute Ornn has negotiated, lock in dedicated contracts, and trade idle reservations on the secondary market. Buyers and sellers aggregate in one place, positioning Ornn as the central marketplace where the two sides meet.

Ornn Data publishes the market insights gathered from that flow — the current buyers, and the OCPI (Ornn Compute Price Index), which tracks live-traded spot GPU prices.

Ornn licenses its index to others: it's partnering with ICE on cash-settled futures, Architect's AX exchange is planning perpetual futures on GPU and DRAM prices using Ornn's data, and Kalshi contracts on GPU prices resolve against Ornn's data.

The value proposition, as I see it: become the de-facto reference price for all transactions, and scale from there. Ornn raised $33 million led by A16z.
